Current Research

Ongoing • Medical AI • XAI • Multimodal Systems

Beyond the Output: Faithful XAI for Medical Image Report Generation

Investigating hallucination detection and explanation faithfulness in medical vision-language models using chest X-ray report generation as a testbed.

  • Studying whether generated clinical reports are grounded in visual evidence.
  • Identifying hallucinated or unsupported statements in generated reports.
  • Linking visual saliency, model reasoning, and clinical correctness in a unified evaluation framework.
  • Technologies: PyTorch, TensorFlow, Vision Transformers, Medical Imaging, XAI.

Selected Research Projects

2026 • Video Understanding • Transformers

Soccer Action Detection Using TimeSformer

Fine-tuned a pretrained TimeSformer on approximately 3,600 annotated SoccerAct10 clips for fine-grained soccer action recognition.

  • Achieved 91.13% Top-1 validation accuracy.
  • Modeled long-range spatiotemporal dependencies using divided space-time attention.
  • Analyzed difficult class distinctions including fouls, short passes, and long passes.
Computer Vision • Image Forensics • Explainability

Image Forgery Detection: ResNet50 + U-Net + Grad-CAM

Built an explainable computer vision pipeline for detecting and localizing image manipulation using the CASIA 2.0 dataset.

  • ResNet50 for classification and U-Net for pixel-level localization.
  • Grad-CAM for interpretable visual evidence.
  • Reported AUC: 0.86 and recall: 0.88.
NLP • Full-Stack AI • Explainable Decision Support

NewsLogic: AI-Powered Fake News Detection System

Designed and deployed a full-stack AI system combining transformer-based classification, rule-based validation, and explanation generation for transparent misinformation analysis.

  • BERT and DistilBERT for multi-signal text analysis.
  • LLaMA-based explanation generation.
  • FastAPI backend with Supabase-backed authentication and storage.
ML + Bioinformatics • Healthcare Research
