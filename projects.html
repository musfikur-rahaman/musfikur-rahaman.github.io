Projects

All projects are openly maintained on GitHub.

  • Beyond the Output: Faithful XAI for Medical Image Report Generation [code]
    A unified evaluation framework linking visual saliency maps, model reasoning chains, and clinical correctness to reduce unfaithful explanations in chest X-ray report generation. Scores explanations on where the model looked, how it reasoned, and whether the clinical findings are correct. In progress.
  • Soccer Action Detection Using TimeSformer [code]
    Transformer-based video understanding for context-dependent soccer actions — 91.13% on SoccerAct10 with divided space-time attention. Repo includes the 44-cell TimeSformer analysis notebook, a full project report, and the published JCSC/ACM paper.
  • NewsLogic: AI-Powered Fake News Detection [code]
    End-to-end fake news classifier — BERT-tiny + DistilBERT ensemble with LLaMA-4-Scout explanations — 83.1% accuracy and 0.91 AUC on 71 live-app cases, deployed as a FastAPI service. Includes 5 architecture diagrams, a final evaluation report, and a working demo.
  • Fish Disease Detection with FishNet CNN [code]
    CNN-based disease detection for South Asian freshwater fish aquaculture — custom FishNet CNN at 92.5% test accuracy across 7 disease classes, plus transfer-learning (71%) and baseline notebooks for comparison. Includes the 48×36 symposium poster and a full project report.
  • MLBioIGE: ML + Bioinformatics for Pulmonary Fibrosis [code]
    Peer-reviewed study on genetic factors in pulmonary fibrosis among COVID-19 patients — 4 DESeq2 notebooks (main cohort + COVID/COPD/IPF comparisons) with volcano plots and PCA visualizations. Biology Methods and Protocols, 2022.
  • Explainable Image Forgery Detection [code]
    ResNet50 + U-Net + Grad-CAM pipeline for detecting and localizing image manipulation — 80.32% accuracy, 0.88 forged recall on CASIA 2.0 — plus a multi-branch EfficientNet-B3 + DCT frequency-feature notebook. Every decision ships with a Grad-CAM heatmap.
  • Programming Sequence Improvement Program (PSIP) [code]
    Multi-year study on retention and learning outcomes in undergraduate CS programming courses — IEEE HCIRA 2023 paper, poster, abstract, two presentation decks, aggregated grade data (DFWI rates), and survey instruments.
  • AI Chatbot — Flask + Hugging Face Inference [code]
    Lightweight web chatbot: a Flask backend with a clean chat UI, powered by the Hugging Face Inference API (openai/gpt-oss-120b) — no GPU required. Sliding-window conversation memory, configurable generation parameters, truncation detection, and /health and /reset endpoints.
  • RAG over Soccer Video-Understanding Literature [code]
    Retrieval-augmented generation playground over a corpus of soccer video-analysis papers. Ingestion layer built with LangChain and PyMuPDF (10-paper corpus); chunking, embeddings, vector-store retrieval, and a citation-backed QA loop on the roadmap.
