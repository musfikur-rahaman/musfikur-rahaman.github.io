  • Beyond the Output: Faithful XAI for Medical Image Report Generation [code]
    A literature survey on reliability in medical AI — now a Preprints.org preprint (2026) — arguing that hallucination and unfaithful explainability are symptoms of the same gap: no mechanism connecting visual evidence, model reasoning, and output correctness. 110 papers collected (2020–2026), 27 selected for thematic analysis across vision-transformer explainability, medical report generation with XAI, and hallucination detection. Key claim: faithfulness in explanation can serve as an early signal for hallucination — a model not grounded in the image produces explanations that reveal it. Trend analysis shows reliability work now leading the field's growth since 2024, yet the evidence-to-reasoning-to-verification pipeline exists only in principle. Repo includes the full 27-paper bibliography and an interactive literature navigator.
  • Soccer Action Detection Using TimeSformer [code]
    Transformer-based video understanding for context-dependent soccer actions — 91.13% top-1 accuracy (91.22% precision, 90.85% recall) on SoccerAct10 with divided space-time attention. Goal kicks, penalties, and substitutions score highest; fouls vs. long passes are the hardest. Fine-tuned on short broadcast clips across all 10 actions, with results from a single training run and an open-in-Colab notebook for reproducibility. Repo includes the 44-cell TimeSformer analysis notebook, methodology diagram, class-wise breakdowns and confusion matrix, a full project report, and the published JCSC/ACM paper.
  • NewsLogic: AI-Powered Fake News Detection [code]
    End-to-end fake news classifier — BERT-tiny + DistilBERT ensemble with LLaMA-4-Scout explanations — 83.1% accuracy and 0.91 AUC on 71 live-app cases, deployed as a FastAPI service. Every verdict ships with a natural-language rationale — the two lightweight BERT variants keep inference fast while the Groq-hosted LLaMA-4-Scout explains each flag in plain language. Repo includes 5 architecture diagrams, a final evaluation report, and a working demo.
  • Fish Disease Detection with FishNet CNN [code]
    CNN-based disease detection for South Asian freshwater fish aquaculture — custom FishNet CNN at 92.5% test accuracy (0.93 macro F1) across 7 categories: healthy fish plus bacterial, fungal, parasitic, and viral diseases. Three-notebook progression from a 40% from-scratch baseline through 71% transfer learning to the final FishNet model, with training curves, sample images, and the confusion matrix on 697 test images. Includes the 48×36 symposium poster and a full project report.
  • MLBioIGE: ML + Bioinformatics for Pulmonary Fibrosis [code]
    Peer-reviewed study on why COVID-19 hits idiopathic pulmonary fibrosis patients so hard — DESeq2 differential-expression analysis on RNA-seq data across COVID/COPD/IPF cohorts, shared-gene and pathway discovery, protein–protein interaction networks for hub genes, and transcription factor–gene mapping toward drug targets. 4 notebooks with volcano plots and PCA visualizations, plus the published paper PDF and final manuscript — the full chain from public GEO data to published finding. Biology Methods and Protocols, 2022.
  • Explainable Image Forgery Detection [code]
    ResNet50 + U-Net + Grad-CAM pipeline unifying classification, pixel-level forgery localization, and visual interpretability — 80.32% accuracy, 0.86 AUC, 0.88 forged recall on CASIA 2.0 — plus a multi-branch EfficientNet-B3 + DCT frequency-feature notebook. Grad-CAM heatmaps key on texture inconsistencies and splicing artifacts, making every verdict auditable. Training curves over 20 epochs and the test confusion matrix are documented, with the checkpoint selected on validation performance.
  • Programming Sequence Improvement Program (PSIP) [code]
    Multi-year study tackling 32%/35%/27% DFWI rates in ATU's programming sequence (COMS 2104/2203/2213) via tutoring labs, Discord/Webex collaboration, pedagogy research, and industry-aligned curriculum. IEEE HCIRA 2023 paper, poster, abstract, two presentation decks, aggregated grade data with DFWI trend charts tracking baseline vs. 2022 rates, and survey instruments — all open for reuse.
  • AI Chatbot — Flask + Hugging Face Inference [code]
    Lightweight web chatbot: a Flask backend with a clean chat UI, powered by the Hugging Face Inference API (openai/gpt-oss-120b) — no GPU required. Sliding-window conversation memory keeps recent turns for context without blowing up the token budget; generation (temperature, top-p, max tokens) is configurable via environment variables, with truncation detection that warns when a reply is cut off. Includes /health and /reset endpoints, a bot logo, and an architecture diagram.
  • RAG over Soccer Video-Understanding Literature [code]
    Retrieval-augmented generation playground over a corpus of soccer video-analysis papers. Ingestion layer built with LangChain and PyMuPDF over a 10-paper corpus (soccer action recognition, video classification, sports video summarization), with rich per-document metadata for precise future citations. The pipeline diagram separates the built ingestion layer from the roadmap: chunking with overlap, embeddings + vector store, similarity retrieval with re-ranking, and a citation-backed QA loop.
