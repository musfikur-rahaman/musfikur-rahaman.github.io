Projects

All projects are openly maintained on GitHub.

  • Beyond the Output: Faithful XAI for Medical Image Report Generation [code]
    A unified evaluation framework linking visual saliency maps, model reasoning chains, and clinical correctness to reduce unfaithful explanations in chest X-ray report generation. Scores explanations on where the model looked, how it reasoned, and whether the clinical findings are correct. In progress.
  • Soccer Action Detection Using TimeSformer [code]
    Transformer-based video understanding for context-dependent soccer actions — 91.13% top-1 accuracy (91.22% precision, 90.85% recall) on SoccerAct10 with divided space-time attention. Goal kicks, penalties, and substitutions score highest; fouls vs. long passes are the hardest. Repo includes the 44-cell TimeSformer analysis notebook, class-wise breakdowns and confusion matrix, a full project report, and the published JCSC/ACM paper.
  • NewsLogic: AI-Powered Fake News Detection [code]
    End-to-end fake news classifier — BERT-tiny + DistilBERT ensemble with LLaMA-4-Scout explanations — 83.1% accuracy and 0.91 AUC on 71 live-app cases, deployed as a FastAPI service. Every verdict ships with a natural-language rationale; repo includes 5 architecture diagrams, a final evaluation report, and a working demo.
  • Fish Disease Detection with FishNet CNN [code]
    CNN-based disease detection for South Asian freshwater fish aquaculture — custom FishNet CNN at 92.5% test accuracy (0.93 macro F1) across 7 categories: healthy fish plus bacterial, fungal, parasitic, and viral diseases. Three-notebook progression from a 40% from-scratch baseline through 71% transfer learning to the final model, with training curves, confusion matrix, the 48×36 symposium poster, and a full project report.
  • MLBioIGE: ML + Bioinformatics for Pulmonary Fibrosis [code]
    Peer-reviewed study on why COVID-19 hits idiopathic pulmonary fibrosis patients so hard — DESeq2 differential-expression analysis on RNA-seq data across COVID/COPD/IPF cohorts, shared-gene and pathway discovery, protein–protein interaction networks for hub genes, and transcription factor–gene mapping toward drug targets. 4 notebooks with volcano plots and PCA visualizations. Biology Methods and Protocols, 2022.
  • Explainable Image Forgery Detection [code]
    ResNet50 + U-Net + Grad-CAM pipeline unifying classification, pixel-level forgery localization, and visual interpretability — 80.32% accuracy, 0.86 AUC, 0.88 forged recall on CASIA 2.0 — plus a multi-branch EfficientNet-B3 + DCT frequency-feature notebook. Grad-CAM heatmaps key on texture inconsistencies and splicing artifacts, making every verdict auditable.
  • Programming Sequence Improvement Program (PSIP) [code]
    Multi-year study tackling 32%/35%/27% DFWI rates in ATU's programming sequence (COMS 2104/2203/2213) via tutoring labs, Discord/Webex collaboration, pedagogy research, and industry-aligned curriculum. IEEE HCIRA 2023 paper, poster, abstract, two presentation decks, aggregated grade data with DFWI trend charts, and survey instruments.
  • AI Chatbot — Flask + Hugging Face Inference [code]
    Lightweight web chatbot: a Flask backend with a clean chat UI, powered by the Hugging Face Inference API (openai/gpt-oss-120b) — no GPU required. Sliding-window conversation memory, configurable generation parameters, truncation detection, and /health and /reset endpoints.
  • RAG over Soccer Video-Understanding Literature [code]
    Retrieval-augmented generation playground over a corpus of soccer video-analysis papers. Ingestion layer built with LangChain and PyMuPDF (10-paper corpus); chunking, embeddings, vector-store retrieval, and a citation-backed QA loop on the roadmap.
