Beyond the Output: Faithful XAI for Medical Image Report Generation

Investigating hallucination detection and explanation faithfulness in medical vision-language models using chest X-ray report generation as a testbed.

Research Direction

  • Study whether generated clinical reports are grounded in the visual evidence present in medical images.
  • Identify hallucinated or unsupported statements in model-generated reports.
  • Evaluate whether model explanations faithfully reflect the evidence used for generation.

Evaluation Framework

  • Link visual saliency maps with generated reasoning and clinical correctness metrics.
  • Compare explanation quality with actual model behavior and output faithfulness.
  • Technologies: PyTorch, TensorFlow, Vision Transformers, Medical Imaging, XAI.
2026 Publication • Video Understanding • Transformers

Soccer Action Detection Using TimeSformer

Developed a transformer-based pipeline for fine-grained soccer action recognition using the SoccerAct10 dataset and a pretrained TimeSformer model.

Methodology

  • Fine-tuned a pretrained TimeSformer on approximately 3,600 annotated clips.
  • Modeled long-range spatiotemporal dependencies using divided space-time attention.
  • Analyzed class-level confusion for visually similar soccer actions.

Key Outcome

  • Achieved 91.13% Top-1 validation accuracy.
  • Identified challenging distinctions among fouls, short passes, and long passes.
  • Published in Journal of Computing Sciences in Colleges, 41(10), 72–81, 2026.

Computer Vision • Image Forensics • Explainability

Image Forgery Detection: ResNet50 + U-Net + Grad-CAM

Built an explainable computer vision pipeline for detecting and localizing image manipulation using CASIA 2.0.

Pipeline

  • ResNet50 for authentic-versus-forged classification.
  • U-Net for pixel-level localization of manipulated regions.
  • Grad-CAM for interpretable visual evidence.

Reported Results

  • AUC: 0.86
  • Recall: 0.88
  • Technologies: ResNet50, U-Net, Grad-CAM, PyTorch, Computer Vision, XAI.

NewsLogic: AI-Powered Fake News Detection System

Designed and deployed a full-stack AI system combining transformer-based classification, rule-based validation, and explanation generation for transparent misinformation analysis.

Modeling

System
